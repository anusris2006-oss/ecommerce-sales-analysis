# 🛒 E-commerce Sales Analysis

## 📌 Project Overview

This project analyzes online retail transaction data using SQL and Microsoft Power BI to understand sales performance, product demand, customer spending, and revenue distribution across countries.

The goal is to transform raw sales data into meaningful business insights through data analysis and interactive visualizations.

## 🎯 Project Objectives

- Analyze total revenue and quantity sold.
- Identify monthly sales trends.
- Compare revenue across countries.
- Identify top-selling products by quantity.
- Analyze customer spending patterns.
- Build an interactive dashboard for exploring sales performance.

## 🛠️ Tools & Technologies

- **SQL** – Data querying and analysis
- **Microsoft Power BI** – Data visualization and dashboard development
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPI creation
- **GitHub** – Project documentation and version control

## 📂 Dataset

The project uses an online retail transaction dataset containing information about invoices, products, quantities, transaction dates, unit prices, customers, and countries.

### Key Columns

| Column | Description |
|---|---|
| InvoiceNo | Invoice or transaction identifier |
| StockCode | Product identifier |
| Description | Product description |
| Quantity | Number of units in a transaction |
| InvoiceDate | Date and time of the transaction |
| UnitPrice | Price per unit |
| CustomerID | Customer identifier |
| Country | Customer's country |

Revenue is calculated using quantity multiplied by unit price, where applicable.

## 📊 Dashboard Features

The Power BI dashboard includes the following KPIs and visualizations:

### Key Performance Indicators (KPIs)
- **Total Revenue:** Overall sales value.
- **Total Quantity Sold:** Total units recorded in transactions.
- **Unique Customers:** Number of distinct customer IDs.
- **Total Orders:** Number of distinct invoice numbers.

### Visualizations
- **Monthly Sales Trend:** Examines changes in revenue over time.
- **Revenue by Country:** Compares revenue across countries.
- **Top 10 Products by Quantity Sold:** Identifies products with high sales volumes.
- **Top 10 Customers by Revenue:** Highlights customers contributing the most recorded revenue.

### Interactive Filters
- Country
- Sales Year

These filters allow users to explore different parts of the dataset interactively.
